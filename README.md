> **Note:** This app was almost entirely generated by [Claude](https://claude.com/claude-code), with only minor manual tweaks from me.

## About

This project started as an experiment in implementing **Material 3
Expressive** (Android 13-16's dynamic color, expressive shapes and motion)
in a real, non-trivial Flutter app - a music player, since that's a UI shape
Material 3 Expressive was designed around. Development is focused
specifically on [Navidrome](https://www.navidrome.org/) as the backend.

## Features

- Browse and search your music library, with playlists and liked songs
- Real audio playback, with a persistent Android media notification
  (play/pause/next/stop) and a session that survives closing the app
- Offline downloads and album art caching
- Playlist management (create, delete, add/remove songs)
- Dynamic color and Material 3 Expressive styling throughout

## Key dependencies

- [`material_3_expressive`](https://pub.dev/packages/material_3_expressive) -
  the full Material 3 Expressive component set this app is built around
- [`just_audio`](https://pub.dev/packages/just_audio) /
  [`audio_service`](https://pub.dev/packages/audio_service) - audio playback
  and the Android media notification
- [`provider`](https://pub.dev/packages/provider) - state management
- [`http`](https://pub.dev/packages/http) - the Navidrome/Subsonic API client
- [`cached_network_image`](https://pub.dev/packages/cached_network_image) -
  album art caching
- [`shared_preferences`](https://pub.dev/packages/shared_preferences) /
  [`path_provider`](https://pub.dev/packages/path_provider) - session
  persistence and offline downloads
